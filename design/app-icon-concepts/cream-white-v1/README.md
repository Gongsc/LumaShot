# LumaShot app icon concept — cream white v1

- `app-icon.svg`: cream-white rounded-square application icon with a pure-white capture-and-light mark.
- `tray-icon.svg`: the same white mark on a genuinely transparent canvas, with a subtle warm-gray optical outline for visibility on light and dark Windows taskbars.
- Both files are vector masters. The PNG files are high-resolution review exports only.
- This concept is not referenced by the application, resource script, tray icon factory, or Visual Studio project.
