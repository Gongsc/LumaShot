# LumaShot app icon concept — sky blue v3

- `app-icon.svg`: sky-blue rounded-square application icon with a pure-white capture-and-light mark.
- `tray-icon.svg`: the same white mark on a genuinely transparent canvas, with a subtle deep-blue optical outline for visibility on light and dark Windows taskbars.
- Both files are vector masters. The PNG files are high-resolution review exports only.
- This concept is not referenced by the application, resource script, tray icon factory, or Visual Studio project.
